Wanderlust -- Travel Agency Website
A responsive travel agency landing page designed to showcase exciting
travel destinations and provide visitors with a simple, engaging
browsing experience.
🌍 Project Overview
Wanderlust is a front-end travel website where users can explore
featured destinations, view starting prices, learn about travel
experiences, and navigate between sections of the page.

The website uses a clean layout, travel imagery, and a blue-and-gold
color theme to create a welcoming travel-focused design.
✨ Features
- Hero section: Welcoming headline, introductory text, and a Book
  Now call-to-action.
- Featured destinations: Destination cards for the Maldives, Swiss
  Alps, Safari Adventure, and Tokyo City.
- Destination details: Each card displays an image, starting
  price, description, and Learn More button.
- Interactive navigation: Smooth scrolling to the Home and
  Destinations sections.
- Destination information: Learn More buttons display the selected
  destination's name, price, and description in an alert.
- About section: Introduces the travel agency and its mission.
- Responsive layout: CSS media queries adapt the layout for
  smaller screens.
- Back to Top: Footer button smoothly returns visitors to the top
  of the page.
🛠️ Technologies Used
- HTML5 -- Website structure and content.
- CSS3 -- Styling, layout, responsive design, and hover effects.
- JavaScript -- Button interactions and smooth scrolling.
- Google Fonts -- Plus Jakarta Sans typography.

🚀 Getting Started
No framework, package installation, or build process is required.
1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Make sure the Assets folder contains the required images.
4. Open index.html in your web browser.
You can also use the Live Server extension in Visual Studio Code for
local development.
💡 How It Works
- Select Book Now to smoothly scroll to the featured destinations.
- Select Learn More on a destination card to view its details in a
  pop-up alert.
- Use the navigation links to move between website sections.
- Select Back to Top in the footer to return to the beginning of
  the page.
🎨 Design
The website uses a light background with blue accents and gold
highlights. Destination images and card layouts help visitors explore
the travel options, while responsive CSS adjusts the layout for mobile
screens.
